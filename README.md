欧易是交易所，不卖订阅套餐，官网展示的是账户层级和费率档位。所以下面这张表列的是新手实际会碰到的入口和门槛，不是套餐对比。建议截图存手机里，操作时对着看。

## KYC 和视频认证：两个都做完，C2C 额度才会放开

身份认证的路径是：App 首页左上角用户中心图标 → 点上方昵称或账号 → 身份认证 → 立即认证 → 上传证件正反面 → 人脸识别。内地用户选身份证就行。

视频认证在另一个入口：App 首页 → 买币 → C2C 买币 → 我的 → 视频认证 → 开始录制。官方对这一步的要求写得很具体：**确保开启声音，打开摄像头，不要连接耳机**。系统会朗读风险提示，你不需要跟读，确认信息无误后在“嘀”声后回答“是的”，然后提交等审核。

这段细节很多教程一笔带过，但它是官方原文，照着做能少重录几次。

视频认证不是可选项。有教程演示时，未做视频认证的账户在 C2C 页面显示总交易额度为 2 万人民币，做完才会放开更高额度；另一份第三方整理的额度表也对得上：完成基础身份认证后，C2C 买币的累计限额约 2 万人民币，完成视频认证后这一限制取消。页面数值会随规则调整，以你账户实际显示为准，但“不做视频认证就买不多”这个结论是稳的。

## C2C 买 USDT：先换稳定币，再去换别的币

法币入金走 C2C。路径是：买币 → C2C 买币 → 选“自选区” → 选 USDT → 输入金额 → 选支付方式 → 挑商家 → 去下单 → 获取付款详情 → 按商家给的账号转账 → 回来点“我已支付”。

为什么不直接用人名币买比特币？有教程解释得挺清楚：直接买 BTC、ETH 这类币，汇率会比较差，损耗大；USDT 是锚定美元的稳定币，1 USDT 大致等于 1 美元，是加密市场里通用的计价筹码，流动性最好。先用人民币换 USDT，再用 USDT 换任何币，中间的损耗更小。这一步对只买几百块的人也成立，金额大了差别更明显。

商家怎么挑，官方页面没展开，第三方实操给了三条标准：

- **去自选区，别用快捷区。** 快捷区省事，系统自动匹配，但价格未必是最优的。
- **看成交量。** 优先选成交几千单甚至上万单的老商家。
- **看成功率。** 越接近 100% 越好，最低也别低于 98%。
- **看商家等级标签。** 有等级标签说明交易经验足、给平台交的保证金多。欧易还会自动筛出带“新手友好”标签的商家，第一次买可以优先从这里选。

VIP 尊享区有资金门槛，小额用户不用看。

付款环节有三个细节值得单独说，都和资金安全有关：

**备注栏必须留空。** 有教程用了很重的措辞提醒，千万不要在备注里写 USDT、欧易、加密货币、虚拟币这类词，轻则这笔交易失败，重则支付宝被冻结。最稳妥的做法就是什么都不写。

**考虑用支付宝小号。** 同一位作者建议专门注册一个支付宝账号用于这类交易，把风险隔离在日常使用的账号之外，一个人可以注册三个支付宝账号。买币环节本身风险不高，因为钱是从你这边出去的、来源干净，真正容易出问题的是卖币收钱那一头。

**核实收款方姓名。** 转账时支付宝会显示收款方姓名，回到订单页对一下是否一致，不一致就别付。

付完款回到欧易点“我已支付”，上传支付凭证，等商家确认收款后放币。USDT 会进你的资金账户。

## 钱到账了却买不了币：资金账户和交易账户是两回事

这是新手最高频的困惑：明明看到账户里有 USDT，去交易页面下单却提示余额不足。

欧易把账户分了两层。C2C 买到、链上充进来的币，进的是**资金账户**，这个账户负责出入金；要做现货、合约这些交易，得先把币**划转**到**交易账户**。路径是：资产 → 资金划转 → 填数量 → 确认。网页端在资产管理里操作，逻辑一样。

据第三方教程，站内划转不收费、到账很快，官方页面没有专门标注这一点，但实际操作中这一步不产生额外成本。真正要记住的是：不划转就没法交易，这一步没有捷径。

## 现货下单：市价还是限价，官方自己怎么解释

划转完成后，App 里连点两次底部“交易”，选“现货”；网页端选交易 → 现货 → 选币对。

选币对时注意一个细节：刚买的是 USDT，就选 USDT 计价的交易对，别选成 USDC 计价的那一个。两者名字像，结算币种不同，选错了还得再换一次。

下单方式有两种，官方对限价的解释值得原样记住：限价委托需要自己输入想买入或卖出的价格，等行情符合预期时自动成交，**此委托不可保证快速成交**；想按当时行情快速成交，可以选市价委托。第一次买、金额不大，市价更省心；想卡一个具体价位，就挂限价，代价是可能一直不成交。

现货页面旁边还有闪兑、合约、DEX、策略、交易广场、期权几个入口。闪兑是系统自动报价，操作最傻瓜，但汇率不划算；合约和杠杆对新手来说风险等级完全不同，有教程作者直接说“千万不要去碰那些看不懂的”。第一次进来，只看现货这一页就够了。

## 链上充提币：网络选错，钱可能真的找不回来

新手真正会用到链上转账的场景通常只有一次：把 USDT 转到虚拟卡平台，或者在两个交易所之间搬。

充币需要先完成身份认证，没认证连充值地址都看不到。路径是：资产管理 → 充币 → 选币种和网络 → 下一步 → 复制地址。充进来的币可以选进资金账户或交易账户。

核心原则只有一条：**发币方选的网络，必须和收币方选的网络完全一致**。USDT 最常用、手续费也最低的通道是 TRC20。一端选 TRC20、另一端选 ERC20，资产不会到账，部分情况下可能永久丢失。真出了错，只能拿交易哈希（TxID）联系客服试着追。

几个官方明写的限制，很多人是转到一半才发现：

- 部分币种暂不支持币安智能链（BSC）充值，也不支持火币生态链（HECO）。
- 充币页面下方会显示**最小到账数量**，低于这个数不会到账。
- 币种要求填 Memo 或 Tag 的，必须填，不填不到账。

提币这边有个容易被忽略的成本：提币费按笔收，和金额无关。USDT 走 TRC20 大约是 1.5 USDT 一笔，走 Arbitrum 之类的网络则不到 0.02 USDT。提 100 USDT 走 TRC20，1.5 USDT 就是 1.5% 的成本，比这笔钱在现货市场买卖一次的手续费高出十几倍。小额提币之前先看一眼费率，值得换个网络就换。

几点读表提示。Maker 从 VIP 7 开始变成负数，意思是平台给挂单方返佣，不是收费。等级判定除了近 30 天交易量，还看账户资产量，具体规则以费率页说明为准。这张表只覆盖现货标准档，合约、期权和特殊交易对的费率是另外的表。

Maker 和 Taker 的区分看的是成交方式，和订单类型没有必然关系。市价单通常算吃单；限价单如果提交后立刻成交，同样算吃单，只有先挂进订单簿、之后才被成交的才算挂单。想确保拿到挂单费率，需要用只做挂单（Post-only）一类的设置。

现货手续费从买到的币里扣。费率页的例子是：市价买入 1 BTC、吃单费率 0.1%，手续费是 0.001 BTC，实际到账 0.999 BTC。

返佣这块，多份第三方资料都提到通过邀请链接注册可享受 20% 的手续费返佣或减免，方向上一致，但官方页面没有明文写死这个比例和形式，注册时以页面显示的权益为准。有第三方教程算过一笔账：普通用户吃单 0.1%，每月买卖合计 15 万 USDT，手续费约 150 USDT，按 20% 返佣每月回来约 30 USDT。这个测算的前提是费率不变、交易量真实，只能当量级参考。

还有一个不在交易手续费里、但会吃掉收益的地方：赚币的活期产品。官方 FAQ 的收益公式是“出借数量 × 年化 ÷ 365 ÷ 24 × 85%”，也就是平台收取市场利息的 15%，新用户补贴那部分年化不抽这 15%。拿 1,000 USDT、市场年化 5% 举例，一年市场利息约 50 USDT，扣完到手约 42.5 USDT。看到“年化 5%”的时候，心里要按 85% 折算。

## 安全设置和防冻卡：出金才是需要小心的那一头

注册完先去安全中心把这几项配好：谷歌验证器或通行密钥、资金密码、提币白名单、防钓鱼码。防钓鱼码的作用很直接，欧易官方发的邮件都会带上这串自定义字符，收到可疑邮件时对一下就知道真假。

C2C 卖币（出金）的四条官方要点，建议背下来：

1. 必须在银行 App 或支付宝、微信账单里确认收款，**切勿根据短信等其他方式确认**。
2. 核实是否为商家实名付款，非实名付款就联系客服或申诉。
3. 没收到钱却点了放币，可以申诉或联系客服。
4. 以订单详情页展示的收付款方式、或聊天窗口卡片里的信息为准，别转错。

防冻卡的思路，第三方总结成四条：用与实名认证一致的本人银行卡收款，拒绝任何第三方代付；用一张非工资卡、非主力资金卡做专用卡；到账后不要立刻大额转出，建议在卡里放几天；避免深夜频繁大额交易。

买币和卖币的风险不对称。买币时钱是从你账户出去的，来源清晰，出问题的概率低；卖币时你收到的是对方的钱，万一那笔钱有问题，被冻的是你的卡。有教程作者说得很直接：如果这笔钱不是急用，不建议频繁出金。
